1. npx create-expo-app@latest aravai-app --template blank
2. cd aravai-app
3. npm install axios react-native-paper
   npx expo install expo-secure-store react-native-safe-area-context react-native-screens react-native-vector-icons
4. Replace App.js and copy the src folder from this zip into the aravai-app folder
5. Update the IP address in src/config.js
6. npx expo start  -> scan the QR code with Expo Go on your phone
